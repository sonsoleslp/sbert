# Qualitative Colour Palette for Topics

A color-blind-friendly qualitative palette used by the package plots.

## Usage

``` r
topic_palette(n)
```

## Arguments

- n:

  Number of colors to return.

## Value

A character vector of \`n\` hex colors.

## Examples

``` r
topic_palette(4)
#> [1] "#E16A86" "#909800" "#00AD9A" "#9183E6"
```
